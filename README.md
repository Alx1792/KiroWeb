# Bey Battle: Metal Fury

Joc retro pixel art de baldufes de batalla per al navegador (HTML + CSS + JavaScript, sense dependències).
Fan game inspirat en la sèrie Metal Fury.

## Com jugar

Obre `index.html` al navegador o visita la versió publicada a GitHub Pages.

- **1 jugador – Torneig**: quarts, semifinal, final i el repte final contra RAGO al Temple Nèmesi.
- **2 jugadors – PvP**: tria blader i estadi i lluita al mateix teclat.

| | Jugador 1 | Jugador 2 |
|---|---|---|
| Moure | W A S D | Fletxes |
| Llançar / poder | Espai | Enter |

`Esc` pausa · `M` música on/off.

## Regles

- Al llançament, prem quan la barra estigui a dalt: més força = més gir.
- Ring out = 1 punt · Spin finish = 1 punt · Burst finish = 2 punts. Guanya qui arriba a 3.
- Els cops carreguen la barra blava. Plena = poder especial.

## Bladers

Gingka (Cosmic Pegasus), Kyoya (Fang Leone), Ryuga (L-Drago Destructor, gir esquerre),
Kenta (Flame Sagittario), Chris (Phantom Orion), King (Variares), Aguma (Scythe Kronos),
Dynamis (Jade Jupiter) i Rago (Diablo Nemesis, es desbloqueja guanyant el torneig).

## Estadis

Clàssic, Gel (relliscós), Volcà (lava als marges), Estel·lar (poca gravetat) i Temple Nèmesi (forat negre).

Música i efectes generats en directe amb Web Audio (chiptune).
